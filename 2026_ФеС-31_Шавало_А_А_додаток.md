# AgroSphere - Платформа управління сільськогосподарськими угіддями

> *Комплексна веб-платформа для управління фермами, полями та паралями з геопросторовим аналізом та плануванням сільськогосподарських робіт.*

## Загальна інформація

- **Тип проєкту**: Монореполіторій з веб-додатком, мобільним додатком та REST API
- **Мови програмування**: 
  - TypeScript (Frontend + Backend)
  - JavaScript (конфігурація)
- **Frontend фреймворк**: Next.js 15 + React 19
- **Backend фреймворк**: NestJS 10
- **База даних**: PostgreSQL 14+
- **ORM**: Prisma 5
- **Архітектура**: Nx Monorepo

## Опис функціоналу

### Frontend (AgroSphere Web)
- Управління паралями - створення, редагування, видалення паралей на інтерактивній карті Mapbox
- Розмічення зон - визначення вибірково-облікових зон в межах паралей
- Аналіз даних - перегляд статистики врожайності та стану ґрунту
- Планування робіт - створення завдань та операцій для сільськогосподарських робіт
- Управління командою - додавання користувачів, розподіл ролей та прав
- Управління платежами - обробка підписок та платежів через Stripe
- Аутентифікація - вхід через OAuth2 із Keycloak

### Backend (REST API)
- Управління клієнтами - реєстрація та управління клієнтів
- Управління фермами - створення та редагування ферм з геолокацією
- Управління паралями - REST API для операцій з паралями та границями
- Управління зонами - API для створення та управління зонами
- Управління завданнями - система завдань зі статусами та пріоритетами
- Управління користувачами - ролі, дозволи, активація/деактивація
- Організаційна структура - підтримка командної роботи і запрошень

### Аутентифікація (Keycloak)
- OAuth2 інтеграція - безпечна аутентифікація користувачів
- Кастомна тема - фірмовий дизайн сторінок входу/реєстрації
- Управління ролями - гибридна система ролей та дозволів

## Як запустити проєкт "з нуля"

### 1. Системні вимоги

```
Node.js: ≥ 18.0
Yarn: 1.22.22+
Docker: для PostgreSQL та Keycloak (опціонально)
PostgreSQL: 14+
```

### 2. Клонування репозиторію

```bash
git clone https://github.com/Andriy-sh/agrosphere.git
cd agrosphere
```

### 3. Встановлення залежностей

```bash
yarn install
```

### 4. Налаштування середовища

#### Для Frontend (`apps/agrosphere/.env.local`):
```env
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key-here

KEYCLOAK_CLIENT_ID=your-client-id
KEYCLOAK_CLIENT_SECRET=your-client-secret
KEYCLOAK_ISSUER=http://localhost:8080/auth/realms/your-realm

NEXT_PUBLIC_MAPBOX_TOKEN=your-mapbox-token
NEXT_PUBLIC_API_URL=http://localhost:4000

NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your-stripe-pk
STRIPE_SECRET_KEY=your-stripe-sk
```

#### Для Backend (`apps/backend/.env`):
```env
DATABASE_URL=postgresql://user:password@localhost:5432/agrosphere_db
PORT=4000
NODE_ENV=development

KEYCLOAK_ISSUER=http://localhost:8080/auth/realms/your-realm
KEYCLOAK_CLIENT_ID=backend-client
KEYCLOAK_CLIENT_SECRET=your-client-secret

JWT_SECRET=your-jwt-secret
JWT_EXPIRATION=24h
```

### 5. Запуск БД (Docker)

```bash
# Запустити PostgreSQL контейнер
docker-compose up -d

# Виконати міграції Prisma
npx prisma migrate dev --schema=apps/backend/prisma/schema.prisma
```

### 6. Запуск проекту

```bash
# Запуск Frontend (термінал 1)
npx nx dev agrosphere

# Запуск Backend (термінал 2)
npx nx dev backend

# Запуск Keycloak (термінал 3, опціонально)
npx nx run-keycloak keycloakify-starter
```

### 7. Доступ до додатка

- Frontend: http://localhost:3000
- Backend API: http://localhost:4000
- Keycloak: http://localhost:8080

## API приклади

### Авторизація (NextAuth)

**POST /api/auth/signin**

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**Response:**
```json
{
  "token": "jwt_token_here",
  "user": {
    "id": "user-id",
    "email": "user@example.com",
    "name": "John Doe"
  }
}
```

---

### Ферми

**GET /api/farms**

Отримати список всіх ферм користувача.

**POST /api/farms**

```json
{
  "name": "My Farm",
  "location": {
    "latitude": 50.450,
    "longitude": 30.523
  },
  "area": 150.5,
  "description": "Family farm"
}
```

**PUT /api/farms/:id**

```json
{
  "name": "Updated Farm Name",
  "area": 200.0
}
```

**DELETE /api/farms/:id**

Видалення ферми.

---

### Парцели

**GET /api/farms/:farmId/parcels**

Отримати список паралей для ферми.

**POST /api/farms/:farmId/parcels**

```json
{
  "name": "Field A",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[[30.5, 50.4], [30.6, 50.4], [30.6, 50.5], [30.5, 50.5], [30.5, 50.4]]]
  },
  "soilType": "chernozem",
  "cropType": "wheat"
}
```

**PUT /api/farms/:farmId/parcels/:parcelId**

```json
{
  "name": "Updated Field",
  "soilType": "loam"
}
```

**DELETE /api/farms/:farmId/parcels/:parcelId**

Видалення парцелі.

---

### Завдання

**GET /api/tasks**

Отримати список завдань.

**POST /api/tasks**

```json
{
  "title": "Посадка озимої пшениці",
  "description": "Посадити озимирую пшеницю на полі A",
  "parcelId": "parcel-id",
  "status": "pending",
  "priority": "high",
  "dueDate": "2026-06-15T00:00:00Z"
}
```

**PUT /api/tasks/:id**

```json
{
  "status": "completed",
  "completedAt": "2026-06-10T14:30:00Z"
}
```

**DELETE /api/tasks/:id**

Видалення завдання.

## Інструкція для користувача

### 1. Реєстрація та вхід

- Натисніть "Увійти" на головній сторінці
- Заповніть форму з email та паролем
- Альтернативно: натисніть "Зареєструватись" для створення нового облікового запису

### 2. Управління Ферм

- Перейдіть до розділу **Ферми** в меню
- Натисніть "Додати ферму"
- Заповніть форму з назвою, локацією та описом
- Натисніть "Зберегти"

### 3. Управління Паралями

- Відкрийте ферму з меню **Мої ферми**
- Натисніть "Відкрити карту"
- Використовуйте інструменти малювання для створення нової парцелі
- Додайте деталі: тип ґрунту, культуру, опис
- Натисніть "Зберегти парцелю"

### 4. Розмічення Зон

- На карті парцелі натисніть "Додати зону"
- Виділіть область вибіркового обліку на карті
- Заповніть параметри зони
- Натисніть "Зберегти"

### 5. Планування Робіт

- Перейдіть до розділу "Завдання"
- Натисніть "Створити завдання"
- Вибіріть парцелю та операцію (посадка, збір, полив тощо)
- Встановіть дату виконання та пріоритет
- Натисніть "Зберегти"

### 6. Управління Командою

- Перейдіть до "Налаштування" → "Команда"
- Натисніть "Запросити користувача"
- Введіть email користувача та виберіть роль
- Натисніть "Відправити запрошення"

### 7. Вихід

- Натисніть на аватар у верхньому правому куті
- Виберіть "Вийти"

## Особливості

### Карто графія
- **Інтерактивна карта Mapbox** - перегляд та редагування паралей на карті
- **Малювання геометрії** - створення і редагування границ за допомогою Mapbox GL Draw
- **Геоспатіальний аналіз** - розрахунки площі, перетинів та інших параметрів за допомогою Turf.js

### Безпека
- **OAuth2 аутентифікація** через Keycloak
- **JWT токени** для захисту API
- **HTTPS/TLS** для зашифрованого передачі даних
- **Роль-базований доступ** (RBAC)

### Масштабованість
- **Монореполіторій (Nx)** для спільного кода
- **Микросервісна архітектура** (можлива розширення)
- **Keycloak** для централізованого управління ідентифікацією
- **PostgreSQL** з міграціями Prisma

## Проблеми і рішення

| Проблема | Рішення |
|---------|---------|
| CORS помилка | Увімкнути CORS middleware у NestJS backend |
| Не підключається до БД | Перевірити DATABASE_URL та статус PostgreSQL |
| Карта не завантажується | Перевірити NEXT_PUBLIC_MAPBOX_TOKEN |
| Помилка аутентифікації | Переконатися що Keycloak запущений та доступний |
| 500 помилка на backend | Перевірити логи: `npm run start:debug --workspace=@agrosphere/backend` |
| Prisma міграції не застосовуються | Запустити: `npx prisma migrate deploy --schema=apps/backend/prisma/schema.prisma` |
